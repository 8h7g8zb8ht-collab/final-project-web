# Школа графического дизайна «AIRY PLANE» ✈️

Веб-приложение для продажи онлайн-курса графического дизайна и обучения студентов. Разработано на **React 19 + TypeScript + Vite + Supabase + Tailwind CSS**.

---

## 🚀 Быстрый старт и локальный запуск

1. **Клонируйте репозиторий**:
   ```bash
   git clone <URL_РЕПОЗИТОРИЯ>
   cd airy-plane
   ```

2. **Установите зависимости**:
   ```bash
   npm install
   ```

3. **Создайте файл `.env`** (на основе `.env.example`):
   ```bash
   cp .env.example .env
   ```
   Вставьте ваши реальные параметры из консоли Supabase:
   ```env
   VITE_SUPABASE_URL="https://ваш-проект.supabase.co"
   VITE_SUPABASE_PUBLISHABLE_KEY="ваш-anon-или-publishable-key"
   ```

4. **Запустите локальный сервер разработки**:
   ```bash
   npm run dev
   ```
   Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## 🗄️ Настройка базы данных Supabase (SQL & RLS)

1. Перейдите в ваш проект в [Supabase Dashboard](https://supabase.com/dashboard).
2. Откройте раздел **SQL Editor** (иконка терминала `>_` в левом меню).
3. Создайте новый запрос (**New Query**), скопируйте всё содержимое файла **`schema.sql`** и нажмите **Run**.
4. Скрипт создаст:
   - Таблицы: `profiles`, `enrollments`, `lessons`, `assignments`, `submissions`.
   - Индексы быстродействия.
   - Триггер `handle_new_user` для автоматического создания профилей учеников при регистрации.
   - Политики Row Level Security (RLS), запрещающие ученикам менять свои роли, статусы оплаты и видеть чужие работы.
   - Хранилища файлов Supabase Storage: `course-materials` и `homework-submissions`.

## ✉️ Настройка уведомлений преподавателю на Email (Resend)

В папке `supabase/functions/notify-teacher/index.ts` подготовлена Supabase Edge Function для отправки писем при сдаче домашней работы учеником.

1. Зарегистрируйтесь на [resend.com](https://resend.com) и получите API Key.
2. В Supabase Dashboard перейдите в **Project Settings → Edge Functions → Secrets**.
3. Добавьте секреты:
   - `RESEND_API_KEY`: ваш ключ Resend.
   - `TEACHER_EMAIL`: `mahmudimunisa8@gmail.com`
   - `FROM_EMAIL`: `AIRY PLANE <onboarding@resend.dev>` (или ваш подтвержденный домен).
4. Разверните функцию через Supabase CLI:
   ```bash
   supabase functions deploy notify-teacher
   ```
*(Если ключ Resend не добавлен, отправка письма мягко пропускается, а домашняя работа всё равно сохраняется в базе и отображается в админ-панели).*

## 🌐 Мультиязычность (RU / TJ / EN) и добавление переводов

Сайт поддерживает три языка:
- **RU** — Русский (основной)
- **TJ** — Таджикский (кириллица: тоҷикӣ)
- **EN** — Английский

Переключатель языков находится в шапке сайта и работает на всех страницах. Выбранный язык сохраняется в `localStorage`.

### Как добавить или отредактировать перевод:
1. Перейдите в папку `src/locales/`:
   - `ru.json` — русский текст
   - `tj.json` — таджикский текст
   - `en.json` — английский текст
2. Найдите нужный ключ (например, `packages.standard.desc` или `hero.subheading`) и измените текст.
3. Сохраните файл — изменения применятся мгновенно.
4. *Примечание:* Содержимое уроков и заданий, которые вы добавляете в админ-панели, сохраняется в том виде и на том языке, на котором вы их внесли.

## 🛡️ Безопасность и публикация на GitHub

1. Файл `.env` **строго исключен** из Git через `.gitignore` (`.env*` с исключением для `.env.example`).
2. Проверьте перед коммитом:
   ```bash
   git status
   ```
   Убедитесь, что `.env` не попадает в список коммита.
3. Отправка в GitHub:
   ```bash
   git add .
   git commit -m "feat: Graphic Design School AIRY PLANE learning platform"
   git push origin main
   ```

### Публикация (Vercel / Netlify / Cloud Run):
- В панели управления хостинга (например, Vercel / Netlify) перейдите в **Environment Variables** и добавьте переменные сборки:
  - `VITE_SUPABASE_URL` = ваш URL
  - `VITE_SUPABASE_PUBLISHABLE_KEY` = ваш Publishable/Anon key
- В **Supabase Dashboard → Authentication → URL Configuration**:
  - В поле **Site URL** укажите домен опубликованного сайта.
  - В **Redirect URLs** добавьте `https://ваш-домен.vercel.app/**`.
